# Diagrams

Source code of the diagrams within the Final Degree Project in code. Diagrams are generated by [Mermaid](https://mermaid-js.github.io/mermaid/#/) and exported to the relevant format. Mermaid is a Javascript-based diagramming and charting tool that renders Markdown-inspired text definitions to create and modify diagrams dynamically.

## Prerequisites

Mermaid sources for the figures in the report. Export them with the [Mermaid CLI](https://github.com/mermaid-js/mermaid-cli) (requires Node.js; `npx` downloads it on first run).

## Render

```bash
cd docs/diagrams

# vector PDF, cropped to the diagram (best for LaTeX)
npx -p @mermaid-js/mermaid-cli mmdc -i {file_name}.mmd -o {file_name}.pdf -b white

# SVG
npx -p @mermaid-js/mermaid-cli mmdc -i {file_name}.mmd -o {file_name}.svg -b white

# high-res PNG fallback, 3x scale
npx -p @mermaid-js/mermaid-cli mmdc -i {file_name}.mmd -o {file_name}.png -s 3 -b white
```

Include the PDF in LaTeX with:

```latex
\includegraphics[width=\textwidth]{diagrams/general-design.pdf}
```
